### Key numbers/facts worth remembering without re-deriving

- Test set: ~400 molecules, ~1,500 spectra visible now (real hidden test
  ~2,500 spectra per the Enveda press release — visible test.parquet is
  described by organizers as a stand-in sample, similar size, NOT the real
  thing).
- Metric MRR@25; matching = RDKit tautomer canonicalization (pinned RDKit
  2026.03.3) → InChIKey14 comparison. Stereochemistry doesn't matter.
- 3 hidden novelty classes, secret distribution, must be handled
  simultaneously (not classify-then-dispatch).
- 9h runtime cap, no internet at submission — pretrained weights/DB dumps
  must be pre-attached as Kaggle Dataset/Model.
- Train: ~2.5M spectra / ~275k unique structures across 11 libraries. Split
  any local train/val **by InChIKey14**, never by spectrum_id (leakage risk
  since the same compound recurs across libraries).
- De novo generation SOTA is weak (~28% top-1 best-in-class on
  MassSpecGym) — don't over-invest there relative to retrieval-based
  strategies for Class 1/2, but do keep a de novo tail generator since
  MRR@25 rewards any top-25 hit, not just top-1.
