## Key facts to remember (don't re-derive)

- Metric: MRR@25. Matching: RDKit tautomer canonicalization (pinned RDKit
  2026.03.3) -> InChIKey14 comparison. Stereochemistry NOT scored.
- 3 hidden novelty classes per molecule (library-searchable / DB-known-no-
  spectra / fully novel), secret mix — must handle all 3 simultaneously,
  not classify-then-dispatch.
- 9h runtime cap. No internet at submission — pretrained weights/DB dumps
  must be pre-attached as Kaggle Dataset/Model artifacts.
- Predictions aggregate per molecule_id across its 1-16 (median 3) spectra
  — never score against a single spectrum in isolation.
- Train ~2.5M spectra / ~275k unique structures across 11 libraries. Split
  train/val by InChIKey14, NEVER by spectrum_id (leakage risk).
- Visible test.parquet is a stand-in sample, NOT the real hidden test —
  schema/format reference only, don't overfit EDA to its exact contents.
- Data license: CC BY-NC 4.0 (non-commercial, attribution required).
- Prize pool $50,000. Entry/merger deadline 2026-12-07. Final submission
  2026-12-14.
